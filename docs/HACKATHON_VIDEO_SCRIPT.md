# Kinetic Academy - Hackathon Video Script

## Recommended Video Length

Target length: 4 to 6 minutes.

Recommended style: screen recording with your voiceover. Keep the app visible most of the time and use short transitions between sections.

## 0:00 - 0:20 Opening

Hello everyone. This is Kinetic Academy, an AI-powered admission preparation platform built for Bangladeshi students.

The main idea is simple: a student should not only know what exam they are preparing for, they should know exactly what to study today, what to revise this week, when to test themselves, and how much time is left before the final exam.

Kinetic Academy turns that pressure into a clear daily plan.

## 0:20 - 0:55 Problem Statement

In Bangladesh, admission candidates often prepare for exams like IBA, Medical, B Unit, C Unit, and D Unit under huge pressure. Many students use scattered notes, random question banks, and coaching routines that are not personalized.

The problem is not only lack of content. The bigger problem is lack of structure.

Students need a system that understands their target exam date, creates a practical study plan, reminds them about daily and weekly exams, and helps them learn deeply instead of memorizing blindly.

That is the problem Kinetic Academy is trying to solve.

## 0:55 - 1:25 Authentication Flow

Here is the opening screen.

The app supports multiple ways to sign in. A student can continue with a mobile number, use Gmail or email verification, or continue with Google Sign-In.

For the hackathon demo, phone sign-in is kept simple and fast so students can enter the app without friction. Email verification is available as an optional verification flow, and Google OAuth is integrated for a professional login experience.

Behind the scenes, authentication is handled through secure server routes and session cookies.

## 1:25 - 1:55 Dashboard

After login, the student reaches the main dashboard.

This dashboard is designed like a study command center. It shows practice actions, progress signals, streak motivation, and entry points to the main learning tools.

The goal is to make the next action obvious. Instead of asking, "What should I do now?", the student can immediately start a practice session, check progress, find a mentor, or open Kinetic Countdown.

## 1:55 - 2:45 Kinetic Countdown And Kinetic Calendar

Now I will open Kinetic Countdown, which is one of the core features of this project.

When the student selects this option, a large visual Kinetic Calendar appears. The student can choose their target exam date and time.

After selecting the exam date, the app shows a live countdown in days, hours, minutes, and seconds.

But this is not only a timer. The countdown becomes the input for the study plan.

The Kinetic Calendar also supports scheduled events. Each date can contain study tasks, daily exams, weekly reviews, reminders, and the final exam target. If multiple events exist on a day, the calendar shows a compact preview, and selecting that date reveals the full list.

This makes the preparation plan visual, editable, and connected to the actual exam deadline.

## 2:45 - 3:35 Gemini AI Study Plan

After the exam date is selected, Kinetic Academy uses Gemini AI to generate a personalized study plan.

The AI considers the selected exam, the remaining days, and the student's preparation flow. It creates daily study tasks, exam checkpoints, review reminders, and subject priorities.

The student can also customize the AI-generated plan. This is important because AI should guide the student, but the student should still stay in control.

The Gemini integration is server-side. The API key is never exposed in the browser. The app also has fallback logic, so if Gemini is not configured or the provider fails, the app can still generate a local plan for demo and development.

## 3:35 - 4:15 AI Daily Exam And Practice

Next is the practice experience.

The student can start a daily exam or topic-based practice from the dashboard or progress map. The app can generate exam-style MCQ questions through the AI daily exam API.

When Gemini is available, the questions are generated by Gemini. If not, the system uses fallback practice questions so the flow never breaks.

This helps students test themselves regularly instead of waiting until the end of their preparation.

## 4:15 - 4:55 Deep Learning Features

Kinetic Academy is not only a question-solving app.

It also includes deeper learning modes inspired by cognitive learning methods.

There is a Feynman-style flow where students explain a concept in simple language. There is Socratic reasoning, where students defend their logic through guided questions. There is a first-principles mode, where students rebuild a concept from basic assumptions.

These features are designed to help students understand why an answer is correct, not just memorize the correct option.

## 4:55 - 5:25 Mentors, Events, And Platform Vision

The app also includes mentor and event discovery concepts.

Students can explore mentor support, live academic sessions, workshops, mock contests, and other preparation events.

The database schema already supports users, sessions, questions, attempts, AI interactions, achievements, events, mentor profiles, teacher courses, and more. So this project is built not only as a demo, but as the foundation of a scalable learning platform.

## 5:25 - 5:55 Technical Summary

Technically, Kinetic Academy is built with Next.js, React, TypeScript, Tailwind CSS, Prisma, PostgreSQL, and Google Gemini.

The app uses server-side API routes for authentication and AI features. It uses Zod validation, rate limiting, environment variables, and safe fallback behavior.

It is deployed through Netlify, with Prisma generation and Next.js build support configured for production deployment.

## 5:55 - 6:15 Closing

Kinetic Academy is built around one mission: helping students prepare with clarity, consistency, and confidence.

Instead of giving every student the same static routine, it creates a dynamic plan around their exam date, their subject focus, and their daily progress.

Thank you for watching. This was Kinetic Academy.
